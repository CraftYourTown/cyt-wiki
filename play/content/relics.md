# Relics

{% hint style="info" %}
This feature is exclusive to our **Towny** server
{% endhint %}

{% hint style="info" %}
In game command: **/relics**
{% endhint %}

Relics are rare artifacts that can be dug up from surface blocks (dirt, grass, sand, etc.) - you'll initially get a "dirty relic" which needs to be cleaned via the **/relics** menu. Depending on the fragility, this can fail and break the relic.

Should it be successful, you can add the relic to your relic inventory by clicking it - you'll get a reward for doing so, as well as a bigger reward when you complete the set it is a part of.

If you already have the relic, it may be an idea to sell or trade with another player to get one you need to complete your set.

<figure><img src="../../.gitbook/assets/image (2).png" alt=""><figcaption></figcaption></figure>

Relics can be found across the whole world, but some are more common in certain biomes - unfortunately the only way to know is to try!
