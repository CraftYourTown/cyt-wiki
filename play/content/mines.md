# Mines

{% hint style="info" %}
This feature is exclusive to our **Skyblock** server
{% endhint %}

{% hint style="info" %}
In-Game Command: **/warp Mines**
{% endhint %}

<figure><img src="../../.gitbook/assets/image (6).png" alt=""><figcaption></figcaption></figure>

Mines are a great way to get gems and ores whilst you're getting settled in to your island.

{% hint style="warning" %}
Be wary! Difficult mobs roam the mines and if you die, you will **drop all gems** in your inventory.
{% endhint %}

### Mine Floors

There are 3 floors to the mines, each floor is more difficult than the last and requires a payment via the NPC at the stairs to unlock. Although it's more difficult, the available ores are better.
